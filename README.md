# Golang Todo Application

REST-API приложение на языке Go для управления списком задач, пользователями и аналитики их продуктивности.

---

## 🛠 Технологический стек

*   **Язык разработки**: Go 1.26
*   **База данных**: PostgreSQL 18
*   **Драйвер БД**: `pgx/v5`
*   **Миграции**: `golang-migrate`
*   **Логирование**: `uber-go/zap`
*   **Конфигурация**: `envconfig`
*   **Валидация**: `go-playground/validator/v10`
*   **Документация**: Swagger / OpenAPI 2.0 (`swaggo/http-swagger`)
*   **Контейнеризация**: Docker, Docker Compose

---

## 🏗 Архитектурные особенности

Проект построен по принципу **Feature-driven Clean Architecture**. Кодовая база разделена на общие инфраструктурные компоненты (`core`) и изолированные бизнес-вертикали (`features`).

### Слои внутри каждой бизнес-фичи:
1.  **Domain (Домен)**: Чистые бизнес-сущности и правила валидации. Не имеет внешних зависимостей.
2.  **Service (Сервис)**: Бизнес-логика приложения. Взаимодействует с инфраструктурными слоями исключительно через интерфейсы (Dependency Inversion).
3.  **Repository (Репозиторий)**: Адаптер для работы с хранилищем данных (PostgreSQL или файловая система).
4.  **Transport/HTTP (Контроллеры)**: Адаптер представления, отвечающий за разбор HTTP-запросов, валидацию DTO и формирование JSON/HTML-ответов.

## 📁 Структура проекта

```text
├── cmd/
│   └── todoapp/                  # Точка входа в приложение
│       ├── Dockerfile            # Оптимизированный Dockerfile для сборки
│       └── main.go               # Инициализация и запуск приложения
├── migrations/                   # SQL-скрипты миграций (golang-migrate)
├── docs/                         # Сгенерированные файлы Swagger-документации
├── internal/
│   ├── core/                     # Общие системные модули (ядро)
│   │   ├── config/               # Конфигурация приложения
│   │   ├── domain/               # Базовые доменные типы (например, Nullable)
│   │   ├── errors/               # Доменные sentinel-ошибки
│   │   ├── logger/               # Настройка логгера Zap
│   │   ├── repository/           # Пул подключений к БД
│   │   └── transport/            # HTTP-сервер, middleware, роутинг, рендеринг ответов
│   └── features/                 # Бизнес-фичи приложения
│       ├── users/                # Фича пользователей (CRUD)
│       ├── tasks/                # Фича задач (CRUD с привязкой к пользователю)
│       ├── statistics/           # Аналитика продуктивности пользователей
│       └── web/                  # Раздача статических файлов (фронтенд)
├── Makefile                      # Скрипты автоматизации разработки
└── docker-compose.yaml           # Конфигурация локальной инфраструктуры
```

## 🚀 Быстрый старт

### Требования:
*   Установленный Go (версии 1.26 или выше)
*   Установленный Docker и Docker Compose
*   Утилита `make`

### 1. Подготовка конфигурации
Скопируйте пример файла конфигурации и заполните переменные окружения:
```bash
cp .env.example .env
```

### 2. Запуск инфраструктуры (БД и проброс портов)
Запустите контейнер с PostgreSQL:
```bash
make env-up
```
Для того чтобы локально запущенное приложение могло подключиться к контейнеру с БД на порту `5432`, запустите порт-форвардер:
```bash
make env-port-forward
```

### 3. Запуск миграций
Примените SQL-миграции для создания схемы данных и таблиц:
```bash
make migrate-up
```

### 4. Запуск приложения

#### Вариант А: Локальный запуск (для разработки)
Запуск Go-приложения непосредственно на хост-машине:
```bash
make todoapp-run
```

#### Вариант Б: Запуск всего стека в Docker (деплой)
Сборка и запуск приложения совместно с базой данных в изолированных контейнерах:
```bash
make todoapp-deploy
```

Приложение будет доступно по адресу: [http://localhost:5050](http://localhost:5050).

## 📖 Документация API (Swagger)

Интерактивная документация API доступна после запуска приложения по адресу:
[http://localhost:5050/swagger/index.html](http://localhost:5050/swagger/index.html)

Для обновления документации после изменения аннотаций в коде выполните команду:
```bash
make swagger-gem
```

## 📋 Список команд автоматизации (Makefile)

| Команда | Описание |
| :--- | :--- |
| `make env-up` | Запускает PostgreSQL контейнер в фоне |
| `make env-down` | Останавливает PostgreSQL контейнер |
| `make env-cleanup` | Удаляет контейнер БД и очищает сохраненные тома (volumes) |
| `make env-port-forward` | Запускает утилиту socat для проброса порта БД на `localhost:5432` |
| `make env-port-close` | Останавливает проброс портов |
| `make migrate-create seq=name` | Создает новые файлы миграции с именем `name` |
| `make migrate-up` | Применяет все незавершенные миграции |
| `make migrate-down` | Откатывает последнюю миграцию |
| `make todoapp-run` | Запускает приложение локально в режиме разработки |
| `make todoapp-deploy` | Собирает образ и запускает весь стек в Docker |
| `make todoapp-undeploy` | Останавливает и удаляет все контейнеры приложения |
| `make swagger-gem` | Генерирует файлы Swagger спецификации по комментариям в коде |
| `make logs-cleanup` | Останавливает сервисы и полностью очищает файлы логов |
| `make ps` | Отображает статус запущенных контейнеров |
